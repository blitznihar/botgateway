Hello world! Meet our new website assistant

Posted on November 21, 2026 by admin · Uncategorized

This page simulates a public WordPress site. The chatbot was added by pasting a single <script> tag into a "Custom HTML" block (or the theme footer). No plugin, no build step.

Notice the theme's hostile CSS (it puts a dashed pink border on every button and iframe). The launcher is unaffected because it renders inside a Shadow DOM.

Visitors chat as guests. Customers can log in (Auth0, simulated by the gateway's dev IdP) and the bot then knows who they are, with no change to the embed code.
